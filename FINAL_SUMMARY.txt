================================================================================
                              KEY FUNCTIONS
================================================================================

filterProducts()
  • Filters by category AND search query
  • Case-insensitive search
  • Updates display in real-time
  • Maintains selected products

addMessageToChat(text, sender)
  • Creates message element
  • Applies user/assistant styling
  • Auto-scrolls to bottom
  • Adds slide-in animation

generateRoutine()
  • Collects selected product JSON data
  • Creates system + user messages
  • Sends to Cloudflare Worker
  • Displays routine in chat
  • Enables follow-up questions

Chat Form Handler
  • Accepts follow-up questions
  • Sends full conversation history
  • Maintains context for AI
  • Displays responses with styling

                    ↓
            Cloudflare Worker
                    ↓
            OpenAI GPT-4.1 API
                    ↓
            Routine Generated
                    ↓
            Display in Chat + Store in History
                    ↓
            User can ask follow-up questions
                    ↓
            History + New Question → API
                    ↓
            Context-aware response returned
